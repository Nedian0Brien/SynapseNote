# Morrow 전체 포팅

수락: 2026-10-19 Dennis Park. 이 intent 하나로 로드맵 1~11단계 전체를 수락했다. 단계마다 spec·plan은 기록으로 남기고 수락을 기다리지 않는다.

## 문제

SynapseNote-Native에는 에디터와 vault 열기·저장까지만 있다. 목표는 Morrow의 기능 전체를 macOS, iPadOS, iOS 앱으로 옮겨 실제 사용자에게 내놓을 수 있는 상태로 만드는 것이고, 일부만 된 상태에서 멈추면 안 된다. 단계마다 수락을 받으면 완성이 늦어진다.

## 원하는 결과

- Morrow README의 기능이 모두 앱에서 동작한다: 페이지 관리(이동, 즐겨찾기, 아이콘, 복제, 휴지통), 탐색(검색, 명령 팔레트, 탭, 홈, 백링크, 아웃라인, 집중 모드), 데일리 노트·`@날짜`·템플릿·태그·작업, 데이터베이스(뷰 5종, 속성 9종, 필터·정렬·그룹, 인라인), 캔버스(손글씨 포함)·그래프, 페이지 히스토리·암호화·플래시카드, 가져오기·내보내기·백업·게시·Markdown 소스 편집, 기기 간 동기화, 빠른 캡처, 테마·글꼴·커버·사용자 CSS, 첫 실행 가이드, 여러 vault.
- macOS와 iPadOS는 위 기능을 모두 제공하고, iPhone은 화면 크기에 맞게 같은 기능을 제공한다. 플랫폼에 없는 동작(예: iOS 전역 단축키)은 그 플랫폼의 방식(공유 확장, 위젯)으로 대신한다.
- 기능 전체를 A안(WebView 편집기 + Morrow TS 코어)으로 먼저 완성한 뒤, 편집기와 데이터 코어를 Swift로 옮긴다.
- 단계마다 자동 검사, 시뮬레이터·macOS 검증, 검증 문서, PR이 남는다.

## 영향 범위

- SynapseNote-Native 저장소 전체. 단계별 브랜치와 PR은 앞 단계 위에 쌓는다.
- 결정 권한: Dennis Park

## 제약

- Morrow·Obsidian vault와 파일 형식이 호환된다. 편집하지 않은 파일은 다시 쓰지 않는다.
- 사용자 데이터를 잃지 않는다. 되돌릴 수 없는 삭제는 확인을 거치고 휴지통을 거친다.
- 전환 단계 전까지 Morrow 파일은 수정하지 않는다.
- 앱 화면에는 SynapseNote 이름만 보인다.
- PR 병합, 배포, 결제가 필요한 계정 작업처럼 되돌릴 수 없는 외부 동작은 사용자에게 따로 확인받는다.

## 범위 밖

- Windows·Linux
- Morrow에 없는 새 기능(AI 기능 포함, Morrow 방침과 같다)
