# Plan: 11d-4 캔버스 페이지

spec: `spec_phase11d-native-screens.md`(11d-4 수정 포함). 브랜치 `feat/swift-canvas`(기준 `feat/swift-db`), 워크트리 `.worktree/swift-canvas`, PR 기준 `feat/swift-db`.

1. **화면 소유**: `PageScreen.canvas(unreadable:)`. 웹 `Page()`는 캔버스에 빈 화면. 읽지 못한 캔버스는 웹 `CanvasPage`와 같은 오류 알림.
2. **읽기**: 호스트 `canvas(id)`가 세션 문서와 `canvasFromDoc` 결과, 페이지 노드마다 제목·아이콘·글 앞부분(`docToPlainText` UTF-16 400)과 없는 페이지 여부를 돌려준다. 페이지 고르기는 `findPages`(Morrow 10개, 캔버스 자신 제외).
3. **저장**: 400ms 뒤 `page.setDoc(canvasDoc(data))`. 원문 편집과 같은 방식으로 웹 적용을 기다리고, 화면을 떠날 때와 앱 저장 전에 마저 저장한다. 원문·캔버스의 저장 대기를 컨트롤러가 한 목록으로 관리한다.
4. **바깥 변경**: `revision`마다 세션 문서를 다시 읽어, 마지막으로 저장한 문서와 다르고 저장 대기와 조작 중이 아닐 때만 바꾼다(Morrow와 같은 규칙).
5. **편집 변환** (`Core/Model/CanvasEdits.swift`, 순수 함수, 단위 테스트·변형 확인): 고정점·마주 보는 면·연결선 곡선, 맞추기·확대, 노드 id, 노드 더하기(그룹은 앞), 이동(그룹 안 노드 함께, 3pt 넘어서부터, JS 반올림), 크기 조절(최소 60×40, 그림은 획 비율), 연결(대상 찾기, 빈 곳이면 새 카드와 연결선 `id+"e"`), 획 마치기(가까운 그림에 합치기, 여백, 0.1 반올림), 지우개, 색, 이름표, 화살표 이동, 되돌리기 기록 100개, `strokePath`(Morrow SVG 문자열과 node 비교), `inkColor`.
6. **화면** (`App/Sources/Canvas/`): 격자 배경, 세계 좌표 층(그룹 → 연결선 → 노드 → 그리는 중인 획), 노드 여섯 종류, 선택·이동·크기·연결 손잡이, 두 번 누르기(카드 추가·편집·페이지 열기·링크 열기·그룹 이름), 연결선 선택과 이름표, 펜·형광펜·지우개와 색·굵기, 카드·페이지·그룹 추가, 되돌리기·다시 하기, 확대·축소·맞추기·두 손가락 확대, 색과 삭제, 하드웨어 키보드 단축키.
7. **확인**: 단위 테스트, iPad에서 위 동작과 파일 내용(탭 들여쓰기 JSON, 페이지 노드는 `file`과 경로), 바깥 편집 반영, 깨진 JSON 알림, DEBUG 비교. 문서·로드맵·PR.

Morrow와 다른 점(예정): 터치에는 Shift가 없어 여러 개 고르기는 하드웨어 키보드 Shift로만, 그룹·연결선 이름표는 원문 대화상자 대신 입력 알림, 마우스 휠 이동·확대는 SwiftUI가 주는 만큼.
