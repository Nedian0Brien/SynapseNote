# 에이전트 채팅에 agent-chat-framework 적용

## 문제

SynapseNote의 기존 에이전트 채팅은 자체 UI로 구성되어 있다. 사용자는 agent-chat-framework의 채팅 컴포넌트를 이 화면에 적용하기를 요청했다.

## 원하는 결과

기존 에이전트 채팅 화면에서 프레임워크의 메시지, 도구 실행 표시, 입력 컴포넌트를 사용한다. 실제 에이전트 요청으로 전송, 스트리밍, 중단, 도구 실행 상태 표시를 확인한다.

## 영향 범위

웹과 데스크톱에서 공유하는 에이전트 채팅 UI, 기존 채팅 상태와 프레임워크 컴포넌트를 연결하는 어댑터, 필요한 의존성과 라이선스 고지.

## 제약

기존 CLI 제공자, 모델 선택, 권한 처리, 세션 복원, 문서·선택 영역 문맥, 이미지 첨부 동작을 보존한다. 기존 편집기와 디자인 토큰을 사용한다. 공개 저장소를 독립적으로 복제해 실행할 수 있도록 로컬 절대 경로 의존성을 남기지 않는다. 다른 작업 공간의 변경을 보존한다.

## 범위 밖

채팅 백엔드 교체, 편집기 전체 재설계, 설치된 앱 교체, main 병합.

## 열린 질문

사용자가 적용 범위와 slug `agent-chat-framework`를 수락했다. 추가 질문 없음.
