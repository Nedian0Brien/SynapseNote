# SynapseNote Legacy Markdown Vault App

이 폴더는 AppFlowy 기반 전환 전에 사용하던 FastAPI/Vite Markdown vault 구현을 보관한다.

## 포함된 항목

- `services/`: 이전 API, 프론트엔드, 백업 서비스
- `deploy/`: 이전 Docker compose 배포 스크립트
- `docker-compose*.yml`: 이전 런타임 compose 파일
- `docs/`, `ops/`, `scripts/`: 이전 구현 문서와 운영 보조 파일

## 사용 기준

이 폴더는 현재 운영 배포 기준이 아니다. SynapseNote의 현재 개발과 배포는 루트
`README.md`에 적힌 AppFlowy 기반 워크트리에서 진행한다.
