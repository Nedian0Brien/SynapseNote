# 11d-3단계 데이터베이스 페이지 검증 결과

- 날짜: 2026-10-20
- 브랜치: `feat/swift-db`(기준 `feat/swift-chrome`)
- 환경: Xcode 27.0, macOS 27.0, iPad Pro 13-inch (M5) 시뮬레이터(iOS 27.0, 앱 컨테이너의 시험 vault)
- 비교 기준: Morrow a2daae1의 `src/app/components/database/{DatabaseView,PropertyValue,data}.tsx`

## 바뀐 것

데이터베이스 페이지 전체를 네이티브가 그린다: 커버와 머리(태그 칸 없음), 보기 탭(추가, 길게 눌러 보기 설정), 도구 막대(필터·정렬·묶기/날짜·속성), 표·보드·달력·목록·갤러리, 새 행, 행 수. 속성 설정(이름·종류·수식·옵션·오름차순·숨기기·삭제), 보기 설정(이름·레이아웃·복제·삭제), 값 편집 9종(글·숫자·선택·여러 선택·날짜·체크·링크·관계·수식). 웹은 데이터베이스 페이지에 빈 화면을 그린다. 다른 페이지 안에 든 데이터베이스와 행 페이지 머리의 속성 줄은 편집기 페이지와 함께 11d-5에서 옮긴다.

- 보기 계산(필터·정렬·묶기·값·수식·종류 변환)은 11d-1에서 Morrow와 맞춘 이식을 그대로 쓴다.
- 화면 안의 변환(Morrow 컴포넌트 안에 있던 것)은 `DatabaseEdits`로 옮겼다.
- 화면의 데이터는 세션 호스트가 한 번에 읽는다(`SessionHost.database`): 데이터베이스, 행, 행마다 첫 그림과 할 일 진행, 관계 값이 가리키는 페이지.
- 바꾼 내용은 화면 사본에 바로 반영하고 명령으로 보낸다. 다음 보고 전에 이어지는 편집이 앞 편집 위에서 계산된다(Morrow의 `getState()`와 같은 효과).
- 종류 바꾸기는 `database.set`과 행마다 `page.setProperties`를 웹 `runAll`로 함께 적용한다(새 `commands` 메시지).

## 함께 고친 것

- **`JSNumber.parse`의 `0x`·`0o`·`0b`**(11d-1): `UInt64(...).map(Double.init)`가 `Double(bitPattern:)`으로 해석되어 `"0x10"`이 16이 아니라 8e-323이 됐다. 수식과 종류 변환이 쓰는 함수다. 숫자 값 테스트에서 드러났다.
- **페이지 제목의 마지막 글자**(11d-2): 제목 칸이 포커스가 있을 때만 이름 바꾸기를 보내서, 빠르게 입력하고 다른 칸을 누르면 마지막 글자가 저장되지 않았다(`Tasks` → `Task.md`). 입력한 변경은 포커스와 상관없이 보내고, 포커스를 잃을 때 남은 글을 한 번 더 보낸다. 다시 확인해 `Task list.md`로 저장됨.
- **화면 고르기의 페이지 종류**(11d-2): `journal`·`templates` 종류 페이지가 웹으로 넘어가, 그 종류의 읽지 못한 페이지는 알림 없이 빈 화면이 될 수 있었다. 웹 규칙대로 캔버스·데이터베이스가 아니면 같은 검사를 한다.

## Morrow와 다른 점

- **관계 칩**: Morrow는 칸·카드 안의 관계 칩을 눌러 그 페이지를 연다. 여기서는 칸과 카드가 단추라 그 안에 단추를 겹칠 수 없어 칩은 표시만 하고, 관계 선택 창에 고른 페이지를 여는 줄과 각 결과의 길게 누르기 메뉴를 두었다.
- **보기 설정 열기**: Morrow는 탭을 두 번 누르거나 오른쪽 클릭한다. 여기서는 탭을 길게 눌러 View Settings….
- **날짜 고르기**: 칸의 날짜는 그래픽 달력으로 고르고, 빈 값에는 Today 단추를 둔다(빈 칸의 달력이 오늘에 있어 오늘을 누르면 바뀌지 않음). 필터의 날짜 값도 날짜 고르기로 받는다.
- **숫자 자판**: iPad 숫자 자판에는 돌아가기 키가 없어 숫자·기호 자판을 쓴다.
- **필터 글 값**: Morrow는 글자마다 보기를 저장한다. 여기서는 리턴이나 포커스를 잃을 때 저장한다(결과는 같고 쓰기가 적다).

## 알려진 한계

- 폴더 노트를 읽지 못한 데이터베이스(`editable: false`)는 화면에서 만들지 못해 확인하지 못했다. 읽기 전용 경로는 기존 `editable` 인자를 그대로 따른다.
- 관계 속성, 수식 속성 편집, 옵션 이름·색 바꾸기, 보기 복제·삭제, 속성 삭제는 단위 테스트로만 확인했다.
- 한글 입력, macOS 화면은 11d-2와 같은 이유로 확인하지 못했다.
- 사용자 CSS는 이 화면에도 적용되지 않는다(11d-2 기록과 같음).
