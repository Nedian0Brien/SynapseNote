- 날짜: 2026-10-19
- 대상 커밋: `feat/webview-editor-spike` 브랜치, Morrow `a2daae1`
- 환경: Xcode 27.0 (27A5218g), macOS 27 호스트, iOS 27.0 시뮬레이터 런타임

## 동작하지 않는 기능 (이번 범위 밖)

- 이미지 블록: Morrow와 같이 vault 파일만 읽는다. 시험 페이지의 data URL 이미지는 "Image not found"로 표시된다.
- 이미지·파일 추가: "Images and files can be added once a vault folder is open." 안내가 뜬다.
- 데이터베이스·캔버스 임베드, 태그 페이지, 데일리 노트: 각각 아직 지원하지 않는다는 안내가 뜬다.
- 편집 내용 저장: 메모리에만 있고 앱을 다시 켜면 가이드 원본으로 돌아간다.

## 구현 중 발견한 것

- **첫 `load`가 버려지는 경쟁 조건**: 페이지가 React 첫 렌더 전에 `ready`를 보내, Swift가 바로 보낸 `load`가 무시되는 경우가 있었다. Host 컴포넌트가 마운트된 뒤 `ready`를 보내고, 그 전에 온 메시지를 보관하도록 고쳤다(`web/src/main.tsx`).
- **macOS 샌드박스와 WebKit**: network client 권한이 없으면 WebKit 콘텐츠 프로세스가 시작되지 않는다. `ENABLE_OUTGOING_NETWORK_CONNECTIONS`를 켰고, 원격 요청 차단은 CSP와 `EditorNavigationDecider`가 맡는다.
- **`viewport-fit=cover`**: iPadOS 26의 떠 있는 사이드바 아래로 본문이 들어가 가려졌다. 이 값을 빼면 WebKit이 안전 영역만큼 본문을 띄운다.
- **`WebView`를 숨긴 채 시작하지 않는다**: 불투명도 0으로 시작하면 WebKit이 레이어를 비활성으로 돌린다. 준비 전에는 진행 표시를 위에 덮는다.
- **번들 크기**: 33MB 중 24MB가 Fluent 이모지 이미지(3,391개)다. 앱 크기를 줄이려면 이모지 표시 방식을 다시 정해야 한다.

## 사용자 확인 요청

아래 항목은 직접 써 보는 확인이 필요하다. 빌드 방법은 `README.md`에 있다.

1. macOS 앱에서 입력 소스를 한국어로 두고 "에디터 검증" 페이지의 문단, 제목, 목록, 체크리스트, 표 셀, 콜아웃에 한글을 입력한다. 조합 중 글자가 둘로 나뉘거나 사라지지 않는지 본다.
2. 같은 페이지에서 Enter, Backspace, ⌘Z, ⇧⌘Z를 눌러 본다.
3. 빈 줄에서 `/`를 누르고 방향키와 Enter로 블록을 고른다. `[[`도 같은 방식으로 고른다.
4. 두 블록에 걸쳐 선택해 복사·잘라내기·붙여넣기를 한다.
5. 가능하면 실제 iPad나 iPhone에서 화면 키보드로 1번을 반복한다.
