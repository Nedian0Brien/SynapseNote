### 그래프 배치가 Morrow와 같은지

`GraphSimulation`은 같은 입력에서 d3-force 3.0.0(Morrow 설정)과 같은 위치를 낸다. 비교값은 이 저장소의 `web/node_modules/d3-force`를 node로 돌려 얻었다.

| 입력 | 단계 | 허용 오차 | 결과 |
|---|---|---|---|
| 노드 4개, 링크 3개 | 1 | 1e-9 | 같음 |
| 노드 4개, 링크 3개 | 50(alpha 0.316…) | 1e-6 | 같음 |
| 노드 40개, 트리 모양 링크 40개 | 120 | 1e-6 | 같음 |

처음 구현은 반발력을 모든 쌍으로 계산했다. 그 결과는 d3를 `theta(0)`(근사 없음)으로 돌린 값과는 같았지만 Morrow 설정(theta 0.9)과는 달랐다. 그래서 d3-quadtree의 Barnes–Hut 근사를 옮겼다. 충돌은 d3처럼 쿼드트리 방문 순서로 처리하고, Morrow의 충돌 반지름(그리는 반지름 + 4)을 쓴다.

## 기록해 둘 동작

- 캔버스를 고치면 Morrow 형식으로 다시 쓴다. 탭 들여쓰기 JSON이고, 손글씨는 `type: "drawing"` 노드다. Obsidian은 이 노드 종류를 그리지 못한다(Morrow와 같다).
- 캔버스는 열람 기록을 남기지 않는다. 2단계에서 정한 대로이며, Morrow와 다른 점이다. 열람 기록을 저장하면 `.canvas` 파일이 다시 쓰이기 때문이다.

## 사용자 확인 요청

1. macOS에서 캔버스에 카드·연결선·그룹을 만들고 손글씨를 지워 본다. 실행 취소·다시 실행도 해 본다.
2. 페이지 본문에서 `/` → Canvas로 인라인 캔버스를 만든다.
3. 그래프에서 노드를 끌어 보고, 트랙패드로 확대·이동해 본다. 페이지 메뉴의 Open Local Graph와 Depth를 바꿔 본다.
