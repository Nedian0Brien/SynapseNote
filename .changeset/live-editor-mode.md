Add a Live editor mode that edits the Markdown source directly while hiding its syntax: headings, emphasis, links, lists, checkboxes, quotes, footnotes, and comments render in place, and typing, deleting, Enter, Tab, and formatting shortcuts follow the same editing rules as the visual editor. Fenced and indented code blocks, tables, math, Mermaid, callouts, accordions, direct and reference images, file embeds, MDX components, and tabs render as editable widgets; their inputs update the corresponding source spans. Horizontal rules render without their Markdown marker. A slash menu inserts common text blocks, tables, math, diagrams, and comments directly into the source. Cmd+K adds, edits, and removes Markdown links while preserving unchanged formatting and titles. Tag and wiki-link suggestions also work inside nested live editors. MDX widgets offer typed property controls, Mirrors can open their source document, and embedded PDFs load their PDFium worker asset correctly. Inline database views retain the document context needed for interactive grids. Document properties remain available while YAML syntax stays hidden.
