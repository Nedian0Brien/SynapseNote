Add a Live editor mode that edits the Markdown source directly while hiding its syntax: headings, emphasis, links, lists, checkboxes, and quotes render in place, and typing, deleting, Enter, Tab, and formatting shortcuts follow the same editing rules as the visual editor. Fenced and indented code blocks, tables, math, Mermaid, callouts, accordions, direct and reference images, file embeds, MDX components, and tabs render as editable widgets; their inputs update the corresponding source spans. Inline database views retain the document context needed for interactive grids. Document properties remain available while YAML syntax stays hidden.
